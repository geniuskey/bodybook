# BodyBook

BodyBook은 [MedicalBooks](https://medical.euiyun.com/) 서가로 옮겨 갔습니다.

- 새 주소: <https://medical.euiyun.com/body/>
- 원고와 코드: [geniuskey/medical-books](https://github.com/geniuskey/medical-books) 저장소의 `body/` 폴더

이 저장소는 옛 주소(`bodybook.euiyun.com`)로 들어온 독자를 같은 쪽의 새 주소로 넘기는 페이지만 배포합니다. 옮기기 전의 원고와 기록은 git 기록에 남아 있습니다.
